FONT CHỮ VIẾT TAY CHO BẢNG TẬP VIẾT
====================================

playwrite-vn.woff2
  Font "Playwrite VN" (Playwrite Việt Nam) — Google Fonts.
  Được thiết kế riêng cho kiểu chữ viết tay tiểu học Việt Nam,
  đủ 29 chữ cái hoa/thường kèm dấu (ă â ê ô ơ ư đ).
  Giấy phép: SIL Open Font License 1.1 — xem OFL-PlaywriteVN.txt
  (được dùng miễn phí, kể cả thương mại, được nhúng vào web).

Cách đổi sang font khác (ví dụ HP001 / HL Hoctro nếu bạn có bản quyền)
--------------------------------------------------------------------
1. Chép file font (.woff2 / .ttf) vào thư mục này.
2. Sửa @font-face ở ĐẦU file css/style.css (đổi url(...) và font-family).
3. Sửa hằng FONT_0 trong js/games.js (mục "Chọn cỡ chữ vừa khung")
   cho khớp tên font-family.
4. Mở lại bảng tập viết kiểm tra chữ có bị cắt dấu hay lệch không.
